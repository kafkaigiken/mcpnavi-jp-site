mcpnaviに掲載する

掲載されているデータについて

mcpnavi は、掲載している内容のひとつひとつに「どこから取得し、いつ確認したか」を付けています。このページでは、その取得方法と、各項目の意味と確認方法を公開します。

情報の取得方法

表示意味
掲載情報と情報確認日 サーバー本体、GitHub、npm、PyPI、公式サイトの公開ページから取得した情報です。取得した日付を、サービスごとに情報確認日として表示します。
不明 公開ページから情報を読み取れなかった項目です。まだ確認していない、または公開されていないという事実で、空欄にはしません。

情報確認日より後に提供者が仕様や料金を変えている場合があります。導入前に公式サイトで確認してください。

掲載が意味しないこと

  • 情報確認日より後に提供者が仕様や規約を変えていないこと。
  • サーバーのソースコードに脆弱性がないこと。コード監査は行っていません。
  • 特定の業務や法令要件に適合すること。適合判断は導入する組織が行います。
  • 提供者との契約条件。契約は提供者と直接結びます。

提供元

項目意味確認方法
提供元 このサーバーを開発・配布している組織または個人の名前です。名前から提供元のページへ移動でき、同じ提供元のMCPサービスを一覧できます。 GitHub、npm、PyPI の公開情報から取得します。
公式サイト 提供元が運営する公式サイトです。リンクの文言は、そのページのタイトルです。 公式ドキュメントとリポジトリから公式サイトのURLを読み取り、ページのタイトルを取得します。
種別 提供元が法人、個人、OSSプロジェクト、官公庁のどれであるかです。 GitHub のアカウント種別、公式サイトの運営者情報、パッケージの公開者情報から判定します。読み取れない場合は不明とします。
国内法人 日本国内に契約や請求の窓口となる法人があるかどうかです。「あり」の場合は会社案内ページへのリンクを付けます。 公式サイトの会社概要ページから判定します。見つからない場合は不明とします。
種別が個人の場合は「対象外（個人）」と表示します。
種別が官公庁の場合は「対象外（官公庁）」と表示します。

接続と認証

項目意味確認方法
提供形態 サーバーをだれが動かすかです。「URLで接続」は提供者が動かしているサーバーに、クライアントからURLを指定して接続する形です。やり取りの内容は提供者のサーバーを通ります。「自分で動かす」は手元のPCや自分のサーバーでプログラムを動かす形で、プログラムを動かせないクライアントからは使えません。クライアントから接続できるかどうかは、接続方式と認証方式にも左右されます。 公式ドキュメントとリポジトリの README に、提供者が動かしている接続URLの記載があるか、自分で動かす手順の記載があるかで判定します。どちらも見つからない場合は不明とします。
認証方式 クライアントがサーバーに接続するときの認証方式です。OAuth 2.1 はMCP仕様が定める方式で、権限の範囲と有効期限を管理できます。 クローラーがサーバーの初期化応答と公式ドキュメントから判定します。
接続方式 クライアントとサーバーが通信する方式です。stdio は、クライアントが手元のPCでサーバーのプログラムを起動して通信します。Streamable HTTP は、URLを指定して接続します。接続先は提供者が動かすサーバーの場合と、自分で動かすサーバーの場合があり、どちらであるかは「提供形態」に表示します。 クローラーがパッケージの設定例と公開エンドポイントから判定します。
HTTPS必須 リモート接続が暗号化された HTTPS に限定されているかどうかです。stdio 専用のサーバーでは対象外です。 クローラーが公開エンドポイントへ HTTP と HTTPS で接続し、HTTP が拒否されるかを確認します。
接続方式がstdioのみの場合は「対象外（stdio のみ）」と表示します。

機能

項目意味確認方法
提供ツール サーバーがクライアントに公開しているツールの名前と説明です。説明文はサーバーが返す原文です。 クローラーがサーバーに接続し、tools/list の応答をそのまま記録します。

運用状況

項目意味確認方法
バージョン 確認時点の最新リリースのバージョンです。 クローラーが npm、PyPI、GitHub リリースから取得します。
最終更新日 最新リリースまたは最後のコミットの日付です。保守が続いているかの目安になります。 クローラーが npm、PyPI、GitHub から取得します。
接続状態 最後にクローラーが接続したときの結果です。 クローラーが定期的にサーバーへ接続し、初期化が成功するかを記録します。

料金

項目意味確認方法
料金体系 利用に費用がかかるかどうかと、かかる場合の課金の仕組みです。 公式サイトの料金ページから判定します。料金ページがない場合は不明とします。
無料枠 費用をかけずに試せる範囲があるかどうかです。 公式サイトの料金ページから判定します。

日本語対応

項目意味確認方法
日本語ドキュメント 導入手順と仕様の日本語版が公式に提供されているかどうかです。 公式ドキュメントまたはリポジトリの README が日本語で書かれているか、日本語版へのリンクがあるかで判定します。見つからない場合は不明とします。
日本語サポート 問い合わせページまたはサポートページが日本語で用意されているかどうかです。 公式サイトに日本語の問い合わせページまたはサポートページがあれば「あり」とします。問い合わせページがほかの言語だけの場合は「なし」、問い合わせページが見つからない場合は「不明」とします。

誤りを見つけたとき

項目名と根拠となる資料を info@mcpnavi.jp 宛にお送りください。確認のうえ、情報を更新します。
