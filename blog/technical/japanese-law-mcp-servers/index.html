法令MCPサーバー：e-Gov 法令APIで条文を取得する24件

法令MCPサーバーは、AIエージェントが日本の法令の条文を取得するためのプラグインです。多くはデジタル庁のe-Gov 法令APIを使います。APIの仕組みと、mcpnaviに掲載している24件の提供形態、接続方式、扱う分野を説明します。

法令MCPサーバーは、AIエージェントが日本の法令を検索し、条文を取得するためのプラグインです。多くはデジタル庁が公開しているe-Gov 法令APIを呼び出します。AIは記憶から書くのではなく、公式のデータから条文を取得して答えに使います。

mcpnaviには、2026年10月2日時点で法令MCPサーバーが24件掲載されています。この記事では、まずe-Gov 法令APIの仕組みを説明します。そのうえで24件を「法令全般」と「特定の分野」に分け、提供形態、接続方式、扱うデータを紹介します。MCPそのものの説明は、MCP入門にあります。

法令MCPサーバーでできること

法令MCPサーバーをAIアプリケーションにつなぐと、AIは会話の途中で法令データを取得できます。たとえば「労働基準法第32条を表示して」と頼むと、AIはサーバーのツールを呼び出します。サーバーはe-Gov 法令APIに問い合わせ、その条文を返します。

サーバーによって返すデータは異なります。法令名で検索するもの、条文を1条ずつ返すもの、法令全体を返すものがあります。改正の履歴や、ある時点の条文を返すものもあります。国税庁や厚生労働省の通達など、e-Gov以外のデータも合わせて返すサーバーもあります。

e-Gov 法令APIの基本

e-Gov 法令APIは、e-Gov法令検索が公開している法令データを、プログラムから取得するための窓口です。デジタル庁が提供しています。

Version 2で加わった機能

デジタル庁は、2025年3月14日に法令API Version 2をリリースしました。お知らせによると、Version 1の機能に加えて、特定の時点での検索と、その時点の条文取得ができます。廃止された法令の検索や、法令本文ファイルのダウンロードも加わりました。Version 1も当面の間は利用できます。

取得できるデータは、平成29年（2017年）4月1日以降のものです。

6つのAPI

仕様書（Version 2.1.139）は、次の6つのAPIを定めています。

API 内容
法令一覧取得API 条件に合う法令の一覧を返す
法令履歴一覧取得API 1つの法令の改正履歴を返す
法令本文取得API 法令の本文を返す
添付ファイル取得API 法令に添付された画像などのファイルを返す
キーワード検索API 条文の中の語句で検索する
法令本文ファイル取得API 法令本文をファイルとして返す

APIの多くは、asofという値で「法令の時点」を指定できます。省略すると、現時点の法令を対象にします。この機能により、法令MCPサーバーは「ある日の条文」を返せます。

データの形式は、法令標準XMLスキーマに沿ったXMLです。JSON形式も選べます。ただし、仕様書はこれを試行版としており、仕様が変わる場合があります。

仕様書には、APIキーなどの認証の定義がありません。

mcpnaviに掲載している法令MCPサーバー

mcpnaviは、法令を扱うサービスにlawのタグを付けています。24件の内訳は次のとおりです。

  • 接続方式：22件がstdioだけに対応しています。2件がStreamable HTTPに対応しています。
  • 提供形態：stdioの22件は、すべて「自分で動かす」です。Streamable HTTPの2件は、「URLで接続」が1件、「不明」が1件です。
  • 認証方式：24件すべてが「なし」です。
  • 種別：個人が21件、法人が2件、OSSプロジェクトが1件です。

「自分で動かす」のサービスは、利用者が手元のPCでプログラムを動かします。提供形態と接続方式の違いは、リモートMCPサーバーとローカルMCPサーバーの違いで説明しています。

法令MCPサーバーを選ぶときに見る点

提供形態と接続方式

24件のうち22件は、「自分で動かす」のstdioサーバーです。利用者は、提供元の手順に沿ってプログラムを用意し、起動コマンドをクライアントの設定に登録します。プログラムを起動できないクライアントでは、このようなサーバーを使えません。

URLだけで接続したい場合は、提供形態に「URLで接続」を含むサービスを探します。URLだけで接続できるサービスの一覧で絞り込めます。

返すデータの単位と範囲

条文を1条ずつ返すのか、法令全体を返すのかを確認します。改正の履歴や、ある時点の条文を返すかどうかはサーバーによって異なります。通達、判例、行政処分の事例など、法令以外のデータを扱うかどうかも確認します。各サービスの説明は、mcpnaviの詳細ページとリポジトリのREADMEにあります。

情報確認日

mcpnaviの値は、公開ページから読み取ったものです。各サービスの詳細ページに、値を確認した日を「情報確認日」として表示しています。値の意味と確認方法は、掲載されているデータについてで説明しています。

法令MCPサーバーを使うときの注意

AIの答えに含まれる条文は、e-Gov法令検索の原文と照らし合わせてください。サーバーが正しく条文を取得しても、AIは要約や引用の段階で文を変える場合があります。

e-Gov 法令APIのJSON形式は、試行版です。仕様が変わると、JSONを使うサーバーが動かなくなる場合があります。サーバーのリポジトリで、最後に更新された日を確認してください。

認証方式が「なし」のサーバーでも、質問の内容はAIアプリケーション側に送られます。業務の情報を含む質問をする場合は、AIアプリケーション側の取り扱いを確認してください。サーバーと認証の関係は、MCPサーバーの認証方式で説明しています。

まとめ

  • 法令MCPサーバーは、AIエージェントが日本の法令を検索し、条文を取得するためのプラグインです。
  • 多くはデジタル庁のe-Gov 法令API（Version 2は2025年3月14日リリース）を使います。APIは時点を指定した条文の取得に対応し、仕様書に認証の定義はありません。
  • mcpnaviには24件を掲載しています。22件が「自分で動かす」のstdioサーバーで、認証方式は24件すべて「なし」です。
  • 法令全般を扱うサーバーが14件、税法・労働法・金融・建築などの分野に絞ったサーバーが10件です。分野別のサーバーの多くは、通達などe-Gov以外のデータも返します。
  • 条文は、e-Gov法令検索の原文で確かめてから使ってください。
