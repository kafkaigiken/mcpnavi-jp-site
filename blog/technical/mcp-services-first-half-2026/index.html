2026年上半期に発表されたMCPサービス：PR TIMESの365件を22カテゴリに分類する

2026年1月から6月に、PR TIMESで自社のMCPサーバーを発表した206社・225サービスを、MCPNaviの22カテゴリに分類しました。業務SaaSが約2割を占め、データを持つ会社の参入も目立ちます。カテゴリごとの例も紹介します。

PR TIMESは、株式会社PR TIMESが運営するプレスリリース配信サイトです。企業、メディア、生活者をニュースでつなぐ場として、多くの会社が新サービスや新機能を発表しています。リリースには発表日、会社名、サービスの内容、問い合わせ先が記載されています。誰でも読めるため、市場の動向を知るうえで最も役立つ情報源の1つです。

MCPNaviは、AIエージェントを支えるMCP連携の情報源になることを目指しています。その一環として、PR TIMESの検索を使い、MCPサービスの発表を調べました。

2026年1月から6月の半年間に、PR TIMESで自社のMCPサーバーを発表した会社は206社でした。リリース数は365件です。1月は29件、6月は109件と、半年で約3.8倍に増えました。

MCPサーバーは、ChatGPTやClaudeなどのAIアプリケーションと外部サービスをつなぐ仕組みです。MCPそのものの解説は、MCP入門を参照してください。

この記事では、365件のリリースを225サービスにまとめ、MCPNaviの22カテゴリに分類します。そのうえで、数字から読み取れる傾向と、カテゴリごとの具体例を紹介します。

調べ方

PR TIMESの検索で、「MCP」「MCPサーバー」「Model Context Protocol」などの語を含むリリースを2,399件収集しました。収集日は2026年10月27日です。リリースの本文を言語モデルで読み、次の4つに分類しました。

  • 自社のMCPサーバーまたはMCP対応を発表している
  • MCPの基盤や支援を提供している
  • MCPクライアントを提供している
  • MCPに触れているだけである

この記事で扱うのは、1つ目の「自社のMCPサーバーまたはMCP対応を発表している」リリースのうち、発表日が2026年1月1日から6月30日のものです。対象は365件でした。

同じサービスが複数回発表されているため、会社とサービスの組み合わせでまとめました。結果は206社・225サービスです。各サービスを1つのカテゴリに分類しました。判断が分かれたものは、最も近いカテゴリを1つ選びました。

次の点に注意してください。

  • 分類は言語モデルが行い、全件を人が読み直したわけではありません。件数は目安です。
  • 発表日は、リリースの日付です。サービスの提供開始日ではありません。「提供予定」や「開発に着手」の発表も含みます。
  • 対象はPR TIMESだけです。他の配信サイトや、会社のブログだけで発表したサービスは含みません。
  • 各サービスの提供形態、接続方式、認証方式は確認していません。MCPNaviに掲載するときは、公開ページから読み取ります。

数字から読み取れること

1. 最大のカテゴリは、日々の業務で使う業務SaaSです

「生産性」が49サービスで、全体の22%を占めます。内容は在庫管理、ERP、人事評価、契約書作成、予約、ECサイト構築、RPAなどです。MCPNaviのカテゴリは、もともとカレンダーやメモ、自動化を想定して作ったものです。業務システム向けのカテゴリが必要かどうかは、今後の課題です。

2. 発表した会社の約8割は、非上場の企業です

206社のうち、161社が未上場です。東証上場は32社、海外市場上場は11社でした。業種は、PR TIMESの分類で「情報通信」が170社（83%）を占めます。大手より中小のSaaS事業者が先に動いています。

3. 自社のデータを持つ会社が、データをMCPサーバーで出しています

少なくとも14サービスが、自社で集めたデータを読ませるためのMCPサーバーです。

  • オークファン：相場データ
  • SalesNow：企業データ
  • QFINDR：国内の企業検索
  • Cabocia：有価証券報告書（EDINET DB）、不動産（FUDOSAN DB）、防災（防災DB）、政策（SEISAKU DB）
  • ハレックス：気象データ
  • Location AI：人流データ
  • スペースシフト：衛星データ
  • REVISIOとエム・データ：テレビの視聴データ
  • IRBANK：財務データ
  • DATAZORA：法人データ（KIJI）

データを売る会社にとって、MCPサーバーはAIに自社データを使ってもらう入口です。

4. データベース、デザイン、監視は、海外ベンダーの日本法人が発表しています

「データベース」の6サービスと「デザイン」の3サービスは、すべて海外ベンダーの日本法人が発表しました。日本オラクル、日本テラデータ、Snowflake、Elasticsearch、Confluent、Figma、Miro、オートデスクなどです。「監視・可観測性」でも、6サービスのうち3つがDatadog、New Relic、Grafana Labsです。国内の会社は、自社のSaaSを持ち込む分野で動いています。

5. 「国内初」「業界初」と掲げるリリースが17件ありました。

以下のように、狭い分野での「初」が並んでいます。

  • 決済代行（SP.LINKS）
  • IDaaS（GMOトラスト・ログイン）
  • 予約・日程調整（Jicoo）
  • グッズ作成（SUZURI）
  • ECカート構築（カラーミーショップ）
  • AEOツール（Answer IO）
  • 議事録（Rimo）
  • PCログ（セブンセンスマーケティング）

※「初」は各社の主張で、MCPNaviが確認したものではありません。

6. LINEを使う販促ツールが、日本らしいまとまりを作っています

ミショナの「エルメ」、a visionの「かんたんラインステップ」、サブスクラインなど、LINEの配信と運用を扱うツールがAIから操作できるようになりました。LINEを前提にしたサービスは、日本のMCPサービスの特徴の1つです。

7. リリースの数と、サービスの数は違います

365件のリリースは、225サービスにまとまります。1つのサービスが何度も発表されています。リリースが多い会社は、ELSOUL LABO（SLV、15件）、Workato（14件）、Boomi（11件）、テラスカイ（10件）です。この4社だけで50件あり、全体の14%を占めます。「リリースの数」だけを見ると、実際より多く見えます。

8. 3つのカテゴリは、0件でした

「バージョン管理」「ファイル・ストレージ」「ブラウザ自動化」は、PR TIMESでの発表がありませんでした。MCPNaviには、GitHub MCP Server、Filesystem MCP Server、Playwright MCPのように、海外提供元が先に出した汎用サーバーがあります。日本の会社は、汎用サーバーより自社製品やデータの連携から始めています。

タイトルを数えると、「Claude」を含むリリースが21件、「ChatGPT」が11件、「Copilot」が4件ありました。これはタイトルに名前があった数で、どのクライアントで使えるかを示すものではありません。接続できるかどうかは、提供形態、接続方式、認証方式の組み合わせで決まります。詳しくは、リモートとローカルのMCPサーバーとMCPサーバーの認証方式を参照してください。

法令MCPサーバーは、AIエージェントが日本の法令の条文を取得するためのプラグインです。多くはデジタル庁のe-Gov 法令APIを使います。APIの仕組みと、MCPNaviに掲載している24件の提供形態、接続方式、扱う分野を説明します。

リモートMCPサーバーとローカルMCPサーバーの違い

リモートMCPサーバーは提供元が動かし、URLで接続します。ローカルMCPサーバーは利用者が手元のPCで動かします。提供形態と接続方式の違い、利用者がすること、認証情報の扱いを説明します。
