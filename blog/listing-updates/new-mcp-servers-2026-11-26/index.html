新着MCPサーバーのご案内（2026年11月）

テスト自動化、広告データ、法人情報、Web検索、画像と動画の生成、旅行の予約など、26件のMCPサーバーを掲載しました。

イ イクバル・アバドゥラ

目次

  1. 国内のサービス
  2. 海外のサービス

MCPNaviに、26件のMCPサーバーを追加しました。国内から8件、海外から18件です。

24件はリモートサーバーで、URLを登録すると接続できます。そのうちティッカーコード、XCrawl、OMOPHubの3件には、手元で動かすnpmパッケージもあります。Hi AUDIT AgentとConcord MCPの2件は、自前で動かすサーバーです。

国内のサービス

リテラ（BringRitera）

SEO・LLMO向けツール「リテラ（BringRitera）」のデータを読み取り、分析や記事のリライト、レポート作成に使えます。読み取り専用で、アドバンスプランで利用できます。

IceShore

AIエージェントがTerraformなどのコードや業務資料を読み込み、システムの構成図と業務の担当者情報をIceShoreに書き込みます。書き込んだ情報は、あとから読み出すこともできます。

ティッカーコード

上場企業の開示を読むサービス「ティッカーコード」のデータを読み取れます。OAuth接続のリモートサーバーと、APIキーで動くnpmパッケージの両方があります。

MagicPod MCPサーバー

テスト自動化サービス「MagicPod」で、テストケースの作成・編集・実行とテスト結果の取得をAIエージェントが行えます。共有ステップの編集やUI情報の取得も可能です。

Hi AUDIT Agent

AIコーディング環境から呼び出し、スマートコントラクト（Solidity、Solana）とWebアプリケーションのコードのセキュリティ監査を行います。自前で動かすサーバーです。APIキーが必要です。

Ask Japan

日本の法人情報、インボイス登録、上場企業、郵便番号と住所を調べられます。日本国内での人手作業の依頼、テイクアウトの注文、大阪での宿泊予約もできます。データ照会は無料です。人手作業は有料です。

Synapse MCP

Google 広告、Microsoft 広告、Meta 広告、Apple Search Ads、Rakuten RMS、Shopify、GA4、Microsoft Clarity、Search Consoleのデータを読み取れます。

STRATA

求人、公共調達の入札、リコール、サイバーセキュリティの注意喚起、証券の開示書類、特許出願、法人登記、地震ハザードなどのデータを照会します。呼び出しごとに従量課金ですが、無料のツールもあります。

海外のサービス

テストと開発

mabl MCP

テスト自動化サービス「mabl」で、テストの作成と実行、結果の分析をAIエージェントが行えます。OAuthまたはAPIキーで接続し、日本語のドキュメントもあります。

Concord MCP

別々のAIコーディングエージェントがメッセージを送り合い、作業を調整するためのサーバーです。自前で動かすサーバーです。MITライセンスのオープンソースで、日本語のドキュメントもあります。

KanbanMCP

AIエージェントがカードを引き受け、作業中の状況を記録し、引き継ぎのメモを残すカンバンボードです。接続先のURLは、ワークスペースごとに決まります。

SandBase

AIモデル、データAPI、サンドボックス、エージェントを1つのAPIキーで検索し、実行します。料金は従量課金で、1日100回までは無料で呼び出せます。

OpenAny

多数の外部APIとAIモデルを1つの接続先から検索し、仕様を確かめてから呼び出します。料金は前払いの従量課金です。

Web検索とデータ

Desearch

WebとX、Reddit、YouTubeなどのSNSを検索できます。Webページの抽出・クロール、人物や企業の検索も可能です。ツールの呼び出しにはAPIキーが必要です。

XCrawl

Webページのスクレイピング、サイトのクロール、検索結果の取得を行います。APIキーをURLに入れて接続するリモートサーバーと、npmパッケージの両方があります。

EarlyLore

プロダクトの検索と比較、市場の動向、デザインの傾向、需要のある分野など、プロダクト調査のデータを読み取れます。ツールの呼び出しにはAPIキーが必要です。

OMOPHub

OHDSIのOMOP標準ボキャブラリ（SNOMED CT、ICD-10、LOINC、RxNormなど）の医療用語を検索し、対応付けます。リモートサーバーとnpmパッケージの両方があります。

Fairquery remote MCP

個人情報の検出と墨消し、メールアドレスの確認、制裁リストとの照合、パッケージの脆弱性の照会、求人ボードの検索を行います。無料のツールと、利用者自身のApifyアカウントに課金されるツールがあります。

業務とデザイン

SoftSync AI

CRMサービスSoftSync AIに、AIエージェントが接続します。OAuthでサインインして使います。

Kite

AIエージェントと人が同じキャンバスでデザインを作成・編集するデザインツール「Kite」のサーバーです。OAuthでサインインして使います。

画像と動画の生成

Kling MCP

Kling AIの画像生成と動画生成をAIエージェントが実行し、生成タスクの状況と結果を受け取ります。KlingのアカウントにOAuthでサインインし、有料のクレジットを使います。

TalkPix

人物の写真と台本から口の動きを合わせた動画を作り、商品写真から短い紹介動画も作ります。前払いのクレジットを使い、無料の試用はありません。

Kinovi

AIモデルの一覧とパラメーターを調べ、費用を見積もってから生成タスクを実行し、結果を受け取ります。MCPサーバーはベータ版で、料金はクレジットの従量課金です。

予約と購入

BRIJ

航空券とホテルの検索と予約、オンラインショップの商品の購入をAIエージェントが行い、代金をUSDCで支払います。

StableDomains

ドメインの検索、購入、更新、移管と、DNSの設定を行います。失効が近いドメインも調べられます。代金はUSDC、USDTまたはカードで支払います。

Toolbox POD

オリジナルデザインのTシャツやパーカーを、AIエージェントがデザインし、見積もり、注文します。発送先は米国内に限られます。

各サービスの詳細は、リンク先のページで確認できます。
