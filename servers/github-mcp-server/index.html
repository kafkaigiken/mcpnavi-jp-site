導入手順

接続URL
https://api.githubcopilot.com/mcp/

URLを登録して接続するクライアントでは、このURLを入力します。

MCPクライアントの設定ファイルに貼り付けるサンプルです。パスや環境変数はご利用の環境に合わせて書き換えてください。

{
  "mcpServers": {
    "github-mcp-server": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "-e",
        "GITHUB_PERSONAL_ACCESS_TOKEN",
        "ghcr.io/github/github-mcp-server"
      ]
    }
  }
}
