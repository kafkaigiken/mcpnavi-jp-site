ツール名説明
search_domainsCheck availability and USD price for a name across TLDs. Each result has premium (boolean; registry premium name) and renewal_price (USD/yr). If the name is taken, suggestions[] lists close AVAILABLE alternatives (live-checked, lowest price first).
agent_signupInstant signup: returns an API key immediately (no form, no email). Guest tier (30 req/min) until claimed by email or wallet. Rate limited per IP (3/hour). Store the key; it is shown once. Pass it on later buying tools as api_key, or set Authorization: Bearer <key> on the MCP connection. Available on the full MCP server (/api/mcp). Not available on the read-only discover MCP (/api/mcp/discover).
quote_domainLive price quote for one domain. Returns premium (boolean) and renewal_price (USD/yr). Premium orders are refused if they exceed what we can currently fund.
create_orderCreate a registration order (a price-locked quote). A 402 is the payment challenge, not an error: follow default_pay (usually gasless USDC on Base with x402), pay the existing invoice, and poll poll_url / check_order — do not create_order again for the same domain while status is awaiting_payment (repeats return the same order with reused:true). Returns quote{price_usd, locked_until}, pay{x402, transfer, checkout_url, poll_url}, payment requirements (exact amount_units — do not round to price_usd) and checkout_url. Policy: check availability right before buying, show the quote to the human and get confirmation before paying; pass idempotency_key (retries with the same key never create a second order; if omitted, identical calls within 15 min share a key, and any open unpaid register for the same buyer+domain is reused). pay_with=balance pays instantly from prepaid balance. Gasless: retry with x402 PAYMENT-SIGNATURE on this order pay URL, or POST /api/v1/register. Card: the 402 also carries stripe_link and stripe_card; hand the human checkout_url. dry_run=true previews quote, renewal and blockers without creating an order.
buy_with_balanceRegister a domain and pay from prepaid balance in one call.
check_orderGet order status and next actions. If awaiting_payment, follow default_pay / pay_reminder (x402 USDC on Base, a transfer, or checkout_url for a human / card) and poll until paid or completed. Do not create another order.
pay_orderSubmit payment for the existing unpaid invoice: tx_hash (EVM hash or Solana signature) of your transfer, or x_payment (base64 x402 EIP-3009 payload, gasless). Prefer default_pay from create_order / check_order. Then poll check_order. Do not create another order.
get_balanceGet your prepaid USD balance and its ledger of top-ups and spends.
topup_balanceCreate a top-up order (USD 1–5000); pay it like any order.
find_dropping_domainsFind expiring, pending-delete and just-dropped domains ranked by a verified quality score (0-100) built from sampled Wayback snapshots (real site vs parked/for-sale), Common Crawl presence, dictionary/brandability and spam heuristics; Majestic referring subnets only count when the archive shows a real site. Parked and spam names are hidden by default; each item includes quality_reasons. Free tier returns top 25; status=available names can be bought immediately with create_order. For presets, estimated value, multi-TLD and keyword filters use drop_radar.
drop_radarDomain Drop Radar: expiring, pending-delete and just-dropped domains filtered by TLD(s), length, keywords, value, quality and drop date, with presets (short-brandable, ai-names, dictionary-com, real-history, cheap-good, dropping-this-week). Returns a summary plus the top 25 with quality reasons, est. value, price, and a ready create_order body for available names or a watch body for others. For up to 500 rows call GET /api/v1/drops/full via x402 ($0.01). Page with limit + cursor (next_cursor in the response); sort with sort + order. To be alerted on future matches call radar_alert.
radar_alertSave a Drop Radar search and get a signed webhook (event radar.match, header X-StableDomains-Signature = sha256 HMAC of the body with the returned secret) and/or email (double opt-in) when new names match or a pending-delete name drops. Free: 3 alerts per IP, 25 with an API key, max 20 events per alert per day. filters takes the same fields as drop_radar.
suggest_domainsFree. Pass domain (e.g. a taken name like agent.com) to get close AVAILABLE alternatives (other extensions, get/try/hq/app variants), live-checked and ranked by price. Or pass idea to generate brandable names for a product idea. Returns only names available right now with USD price and checkout_url.
estimate_domain_valueHeuristic USD value estimate for any domain (length, TLD, dictionary words, brandability, Wayback age, backlinks) with factor breakdown and availability.
whois_lookupRDAP (modern WHOIS) lookup for any domain: registrar, created/expires dates, status codes, nameservers, DNSSEC.
domain_reportFull public-data report for any domain: registrar, dates, status codes in plain English, DNS, website and hosting, HTTPS certificate, email (SPF/DMARC/DKIM/MTA-STS/TLS-RPT/BIMI), subdomains, transfer readiness, and our register/transfer/renewal prices when we sell that ending.
dns_email_checkDNS + email security audit via DNS-over-HTTPS: A/AAAA/MX/NS/CAA, SPF, DKIM (common or given selectors), DMARC policy, grade A-F and concrete fixes.
is_domain_droppingIs an expired domain about to become available? Returns lifecycle (grace, redemption, pending delete, available, registered), estimated drop date and backlink data if in our drop feed.
domain_historyInternet Archive history for a domain or page URL: earliest and latest snapshots (with view links), snapshot/month counts, unique pages, years active, status-code mix, yearly timeline, and a short former-use title check (casino/adult/pharma/loan flags). Read-only. Free.
watch_domainGet notified when an expiring domain changes status or drops (becomes registrable). Pass webhook_url (active immediately, POSTs JSON events domain.status_changed / domain.available with a ready order_api body) and/or email (double opt-in). Free.
set_url_forwardFREE 301 URL forwarding for a domain you registered with us: forward the whole domain (subdomain '@', also covers www) or a subdomain to any https URL. Points DNS at our redirect service. preserve_path keeps /path?query.
list_url_forwardsURL forwards configured on a domain you own.
apply_dns_templateFREE one-call DNS setup for a domain you own. template: vercel | netlify (params.site) | github-pages (params.user) | google-workspace | microsoft-365 | zoho-mail (params.region: com|eu|in|com.au). Replaces only the conflicting web or MX/SPF records.
get_dnsNameservers and DNS records (A/AAAA/CNAME/MX/TXT) of a domain you own.
set_dnsSet DNS records and/or nameservers of a domain you own. records: [{type: A|AAAA|CNAME|MX|TXT|NS (SRV/CAA/ALIAS not supported on hosted DNS: use custom nameservers), name: '@'|sub, value, ttl?, priority? (MX)}]. mode 'replace' (default) replaces the FULL record set; mode 'merge' adds/updates the given records, deletes any in remove [{type,name,value?}], and keeps everything else (safer for adding MX/TXT next to a website).
renew_domainRenew a domain you own. Returns USDC payment requirements (402), or pay_with=balance to renew instantly from prepaid balance. dry_run=true previews quote, new expiry and blockers without charging.
set_notification_webhookSigned account webhook (returns secret). Events: domain.registered, domain.registration_pending, domain.registration_completed, domain.transfer_started, domain.transfer_completed, domain.renewed, domain.expiring, dns.changed. Verify X-StableDomains-Signature = sha256 HMAC of the raw body with the secret; retries for 24h, dedupe on X-StableDomains-Delivery. null to remove.
transfer_domainTransfer a domain in from another registrar using its auth/EPP code; paid in USDC (adds 1 year). Unlock it at the current registrar first. Completes in ~5-7 days.
create_cartRegister up to 20 available domains with ONE payment (exact total in the 402). Returns a price-locked quote, checkout_url for a human to pay, and is idempotent via idempotency_key. After payment each is registered; any failure is refunded to prepaid balance.
get_referral_linkReferral link for a code (?ref=<code>, 30-day first-referrer attribution). This tool is read-only. Pass code for a known public referral code — no auth needed; the link is deterministic. Omit code and sign in (or send an API key) to get or create your own code — no payout address required to activate; earnings accrue until you set one. Earn $0.60 per .com you refer, $0.51 per .xyz, paid weekly in USDC. Programme terms: https://stabledomains.net/affiliates.json. Available on the full MCP and the read-only discover MCP (/api/mcp/discover).
get_referral_statsReferral stats (read-only). Pass code for public aggregate-safe counts on a known code (clicks, sales, referred users; no payout address or earnings ledger) — no auth needed. Omit code and sign in (or send an API key) for your own full dashboard including earnings and payouts. Stats follow the account and API key that own the widget or referral code — use that owner key, not a guest/secondary key. Programme terms: https://stabledomains.net/affiliates.json. Available on the full MCP and the read-only discover MCP (/api/mcp/discover).
set_payout_addressSet the Base USDC address that receives your weekly referral payouts (null to clear). Optional to activate — get_referral_link works first; earnings accrue until an address is set. Crypto-only programme (USDC on Base). Affiliate setup only — not a purchase. Available on the full MCP server (/api/mcp). Not available on the read-only discover MCP (/api/mcp/discover).
set_auto_renewTurn auto-renew on/off for a domain you own and/or fund its renewal balance (vault). deposit_usd moves USDC from your prepaid balance (topup_balance) into the domain's vault; withdraw_usd moves it back. The daily job renews 1 year when ≤30 days from expiry if the vault covers the price, otherwise emails reminders at 30/14/7/1 days.
get_renewal_balanceAuto-renew vault for a domain: renewal balance, 1-year renewal price, whether it is covered, shortfall, days to expiry and ledger. Omit domain to list all your domains' renewal balances.
search_agentsSearch the StableDomains.net agent directory (approved AI agents and MCP servers) by keyword or capability. Returns name, description, url, endpoint_url, mcp_url, capabilities, payment_methods and profile_url.
get_agentGet one agent directory profile by slug.
list_my_agentAgent profiles you submitted (any status: pending, approved, rejected) with review notes. Submit a new one with POST /api/v1/agents (auth required, moderated).
list_domainsList the domains owned by the caller, with expiry dates and status.
contact_supportOpen a support ticket with a person at StableDomains (order, payment, DNS, transfer, account or abuse issues). Pass the order_id or its SD- ref if there is one. A person replies by email to the given address; the response is a ticket ref (T-XXXXXX). Do not include secrets, API keys or wallet keys in the message.
