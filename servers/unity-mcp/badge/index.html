Unity MCP の掲載バッジ

mcpnavi.jp に掲載されているサービスの提供元は、自サイトにバッジを貼って掲載ページにリンクできます。

バッジは、サービスが mcpnavi.jp に掲載されていることを示します。掲載ページには、情報確認日つきのデータがあります。 バッジは、審査・推奨・安全保証ではありません。

貼り付け方

言語と配色を選んで、HTMLをコピーを押します。 自サイトの HTML に貼り付けます。リンク先は、このサービスの掲載ページです。 画像は mcpnavi.jp から読み込まれます。ファイルのコピーは不要です。

利用条件

画像はそのまま使います。文言、配色、比率を変えないでください。 リンク先は、このサービスの掲載ページだけにしてください。 掲載が終了したときは、バッジを外してください。

バッジは、審査・推奨・安全保証ではありません。 掲載ページの内容は、情報確認日に公開ページから取得したものです。
