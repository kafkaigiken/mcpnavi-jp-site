Setup

Connection URL
https://api.githubcopilot.com/mcp/

In a client that connects by a registered URL, enter this URL.

Paste this into your MCP client's configuration file. Adjust paths and environment variables for your environment.

{
  "mcpServers": {
    "github-mcp-server": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "-e",
        "GITHUB_PERSONAL_ACCESS_TOKEN",
        "ghcr.io/github/github-mcp-server"
      ]
    }
  }
}
