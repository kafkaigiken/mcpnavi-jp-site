Listing Updates2026-11-26

New MCP server listings (November 2026)

We have added 26 MCP servers for test automation, ad data, Japanese company records, web search, image and video generation, travel booking and more.

I Iqbal Abdullah

Contents

  1. Services from Japan
  2. International services

We have added 26 MCP servers to MCPNavi. Eight are from Japan and 18 are from overseas.

Twenty-four are remote servers: you register the URL and connect. Three of them, Ticker Code, XCrawl and OMOPHub, also offer an npm package that you run on your own machine. Hi AUDIT Agent and Concord MCP run on your own machine only.

Services from Japan

リテラ（BringRitera）

Lets an AI agent read the data of the SEO and LLMO tool BringRitera for analysis, article rewrites and reports. It is read-only and included in the Advance plan.

IceShore

An AI agent that has read code such as Terraform and business documents writes system diagrams to IceShore, with who uses each part for which work. The agent can read them back too.

ティッカーコード

Gives an AI agent the data of Ticker Code, a reader for the disclosures of listed Japanese companies. It offers a remote server with OAuth and an npm package that runs with an API key.

MagicPod MCPサーバー

Lets an AI agent create, edit and run test cases and fetch test results in the test automation service MagicPod. It can also edit shared steps and read UI information.

Hi AUDIT Agent

An AI coding environment calls it to audit the security of smart contract code (Solidity, Solana) and web application code. It runs on your own machine and needs an API key.

Ask Japan

Lets an AI agent look up Japanese company records, invoice registrations, listed companies, postcodes and addresses. It can also request human tasks in Japan, takeout orders and stays in Osaka. The data lookups are free, and the human tasks are paid.

Synapse MCP

Lets an AI agent read data from Google Ads, Microsoft Advertising, Meta Ads, Apple Search Ads, Rakuten RMS, Shopify, GA4, Microsoft Clarity and Search Console.

STRATA

Lets an AI agent query job postings, procurement tenders, recalls, cyber advisories, securities filings, patent filings, the corporate registry, seismic hazards and more. Calls are billed per use, and some tools are free.

International services

Testing and development

mabl MCP

Lets an AI agent create and run tests and analyse their results in the test automation service mabl. It connects with OAuth or an API key, and it has Japanese documentation.

Concord MCP

Lets separate AI coding agents send each other messages and coordinate their work. It runs on your own machine, is published under the MIT licence and has Japanese documentation.

KanbanMCP

A kanban board where AI agents claim a card, check in while they work and leave a handoff note. Each workspace has its own endpoint URL.

SandBase

Lets an AI agent search and run AI models, data APIs, sandboxes and agents with one API key. Usage is billed per call, with 100 free calls a day.

OpenAny

Lets an AI agent search many third-party APIs and AI models from one endpoint, inspect them and call them. Usage is prepaid and billed per call.

Web search and data

Desearch

Lets an AI agent search the web and social platforms such as X, Reddit and YouTube. It can also extract and crawl web pages and search for people and companies. Tool calls need an API key.

XCrawl

Scrapes web pages, crawls sites and fetches search results. It offers a remote server that takes the API key in the URL and an npm package.

EarlyLore

Gives an AI agent product research data: product search and comparison, market trends, design patterns and areas of demand. Tool calls need an API key.

OMOPHub

Searches and maps medical terms in the OHDSI OMOP vocabularies (SNOMED CT, ICD-10, LOINC, RxNorm and others). It offers a remote server and an npm package.

Fairquery remote MCP

Detects and redacts personal data, checks email addresses, screens names against sanctions lists, queries package vulnerabilities and searches job boards. Some tools are free, and others bill your own Apify account.

Business and design

SoftSync AI

Connects an AI agent to the CRM service SoftSync AI. You sign in with OAuth.

Kite

The server of Kite, a design tool where AI agents and people create and edit designs on the same canvas. You sign in with OAuth.

Image and video generation

Kling MCP

Lets an AI agent run Kling AI image and video generation and fetch the status and result of each task. You sign in to a Kling account with OAuth and spend paid credits.

TalkPix

Makes a lip-synced video from a photo of a person and a script, and a short product video from a product photo. It uses prepaid credits and has no free trial.

Kinovi

Lets an AI agent list AI models and their parameters, estimate the cost, run a generation task and fetch the result. The MCP server is in beta, and usage is paid with credits.

Booking and buying

BRIJ

Lets an AI agent search and book flights and hotels and buy products from online shops, paying in USDC.

StableDomains

Searches, buys, renews and transfers domains and sets DNS records. It can also look into domains that are about to drop. Payment is in USDC, USDT or by card.

Toolbox POD

Lets an AI agent design, price and order custom T-shirts and hoodies. Orders ship to addresses in the United States only.

You can read the details of each service on its page.
