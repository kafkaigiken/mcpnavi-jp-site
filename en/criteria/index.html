About the data

Every value mcpnavi shows carries where it was read from and when it was checked. This page explains how values are read, and what each field means and how it is checked.

How the information is read

Shown asMeaning
Listed information and last-checked date Information read from the server itself, GitHub, npm, PyPI or the official site. The date it was read is shown once per service as the last-checked date.
Unknown A field whose information could not be read from a public page. It means not yet checked or not published, and it is never left blank.

The provider may have changed the specification or pricing after the last-checked date. Confirm on the official site before adopting.

What a listing does not mean

  • That the provider has not changed the specification or terms since the last-checked date.
  • That the server's source code has no vulnerabilities. No code audit is done.
  • That it fits a particular business or legal requirement. The adopting organisation decides that.
  • The contract terms with the provider. Contracts are made directly with the provider.

Provider

FieldMeaningHow it is checked
Provider The organisation or person that develops and distributes this server. The name links to the provider page, which lists every MCP service from the same provider. Read from the public GitHub, npm or PyPI pages.
Website The official website the provider runs. The link text is the title of that page. The site's URL is read from the official documentation and the repository, and the page's title is fetched.
Type Whether the provider is a company, an individual, an open-source project or a government body. Read from the GitHub account type, the operator information on the official site and the publisher of the package. Unknown when none of them states it.
Japanese entity Whether a company in Japan can sign the contract and issue the invoice. "Yes" links to the company page. Read from the company page on the official site. Unknown when none is found.
When Type is Individual, this shows as "Not applicable (individual)".
When Type is Government body, this shows as "Not applicable (government body)".

Connection and authentication

FieldMeaningHow it is checked
Hosting Who runs the server. "Connect by URL" means the provider runs the server and the client connects to it with a URL. What the client sends and receives passes through the provider's server. "Run it yourself" means you run the program on your own computer or your own server, so a client that cannot run programs cannot use it. Whether a client can connect also depends on the transport and the authentication method. Read from the official documentation and the repository README: whether they state an endpoint URL the provider runs, and whether they give steps to run the server yourself. If neither is found, the value is Unknown.
Authentication How a client authenticates to the server. OAuth 2.1 is the method the MCP specification defines; it scopes permissions and expires tokens. When a server accepts several methods, every one is shown. The crawler reads the server's initialize response and the official documentation.
Transport How the client and the server talk to each other. With stdio, the client starts the server program on your own computer. With Streamable HTTP, the client connects to a URL. That URL can be a server the provider runs or a server you run yourself; "Hosting" states which. The crawler reads the package's configuration examples and the public endpoint.
HTTPS required Whether remote connections are limited to encrypted HTTPS. Not applicable to stdio-only servers. The crawler connects to the public endpoint over HTTP and HTTPS and checks that plain HTTP is refused.
When Transport is stdio only, this shows as "Not applicable (stdio only)".

Capability

FieldMeaningHow it is checked
Tools The names and descriptions of the tools the server exposes to clients. Descriptions are the server's own text. The crawler connects to the server and records the tools/list response as is.

Operations

FieldMeaningHow it is checked
Version The latest release version at the time of checking. The crawler takes this from npm, PyPI or GitHub releases.
Last updated The date of the latest release or last commit. A guide to whether the server is still maintained. The crawler takes this from npm, PyPI or GitHub.
Status The result of the crawler's last connection. The crawler connects to the server on a schedule and records whether initialization succeeds.

Pricing

FieldMeaningHow it is checked
Pricing model Whether use costs money and, if so, how it is charged. Read from the pricing page on the official site. Unknown when there is no pricing page.
Free tier Whether there is a range of use that costs nothing. Read from the pricing page on the official site.

Japanese support

FieldMeaningHow it is checked
Japanese documentation Whether official Japanese setup and reference documentation exists. Read from whether the official documentation or the repository README is written in Japanese, or links to a Japanese version. Unknown when neither is found.
Japanese support Whether the contact page or the support page is available in Japanese. "Yes" when the official site has a contact page or a support page in Japanese. "No" when the contact page is only in another language. "Unknown" when no contact page is found.

Found an error?

Send the field name and the supporting source to info@mcpnavi.jp. We check it and update the information.
